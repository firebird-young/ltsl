功能说明

一、页面用途

  • 生成并管理小程序二维码：为小程序首页与课程生成带流量场景参数的二维码，用于线下物料、外部渠道投放，扫码直达小程序对应页面。
  • 页面顶部实时统计已生成的二维码数量。

二、生成流程

  • 点击右上角「＋ 生成二维码」，先在步骤 1 选择类型：
  • 首页二维码：扫码进入小程序首页，可附加流量场景（非必填）；
  • 课程二维码：需先选择课程分类（文博研学 / 非遗文化 / 艺术臻品 / OPC 创业），课程名称下拉会按所选分类联动筛选（仅展示该分类下「上线 / 下线」状态课程，草稿不可选），再可附加流量场景（非必填）；
  • 商品二维码：需先选择商品品类（日用品 / 工艺品 / 食品），商品名称下拉会按所选品类联动筛选（仅展示已上架商品，下架不可选），再可附加流量场景（非必填）；
  • 流量场景来源为「流量场景管理」中维护的场景数据。

三、链接规则

  • 首页二维码：weapp://litai/pages/index/index?scene=场景名；
  • 课程二维码：weapp://litai/pages/course/detail?courseId=课程ID&scene=场景名；
  • 商品二维码：weapp://litai/pages/goods/detail?productId=商品ID&scene=场景名；
  • 未附加流量场景时不携带 scene 参数。

四、生成记录列表

  • 列表展示：二维码编号、类型、内容、附加流量场景、链接、生成时间；
  • 筛选：按类型（首页 / 课程 / 商品）与关键词（课程名称 / 课程分类 / 商品名称 / 商品品类 / 流量场景）模糊过滤。

五、查看二维码

  • 每条记录操作列提供「查看 / 删除」按钮：「查看」点击后弹窗放大展示二维码；「删除」需二次确认，确认后从列表中移除该条生成记录（不可恢复，但不影响已生成的二维码实际投放）。
  • 弹窗内展示二维码图与内容信息（类型 / 内容 / 场景 / 链接 / 生成时间）；
  • 支持下载二维码保存图片（原型演示）。
