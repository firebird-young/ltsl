功能说明

一、页面用途

  • 用户订单管理页以用户为单位，后台查看和管理所有订单，支持按状态筛选、按条件搜索、查看订单详情、发起退款及导出数据。

二、状态标签页

  • 顶部标签页按订单状态分组：全部 / 待成团 / 退款中 / 已退款 / 待出行 / 已核销 / 已过期，各标签显示对应数量，点击仅展示对应状态订单。

三、搜索筛选

  • 支持按订单编号、用户手机、课程名称、拼团订单编号、场次时间、场次名称精确搜索。
  • 点击「查询」应用条件，「重置」清空条件。

四、订单列表

  • 表格展示：订单编号（可点击查看）、用户账号、课程 / 场次、出行人 / 规格、总金额、优惠金额、实付金额、订单状态、拼团确认时间、下单时间、关联拼团。
  • 出行人 / 规格列合并展示：每个出行人单独一行，包含姓名 + 性别 + 类型标签（学生 / 家长）及其规格与单价（如：李浩宇 学生带午餐 ¥199），不重复展示数量。

五、订单详情

  • 点击订单编号或「查看」弹出详情弹窗，包含：订单信息（编号、状态、金额、下单 / 拼团确认时间等）、用户与出行人（用户账号、联系手机号、出行人）、课程信息、关联拼团（拼团编号与状态）。

六、退款操作

  • 非退款 / 已退款状态订单提供「退款」按钮，弹窗填写退款比例（%）与退款备注，确认后进入「退款中」并自动转为「已退款」。
  • 「退款中」「已退款」订单提供「退款信息」查看，展示退款流水号、状态、备注、退款时间、到账时间、付款 / 退款金额。

七、数据导出

  • 右上角「导出」按钮，将当前状态下的列表数据导出为表格文件。
