📖 功能说明

课程发布页用于管理员创建研学课程，填写基本信息、销售设置（含自助核销与场次方案）后暂存或发布。本次仅新增自助核销与场次方案两个功能点。

一、自助核销

  • 位于"销售设置"中，开关为不开启 / 开启二选一。
  • 不开启：用户端订单页不展示滑动核销，出行前仅按活动时间到场参与。
  • 开启：展开"课程开始前 X 天"步进器，用于设置自主核销的开放时间（即出行前 X 天起，用户可在订单详情页滑动核销）。
  • 开启后，达到开放时间的订单会展示滑动核销入口，核销后用户进入研学企微群。

二、场次方案

  • 必填项。通过右上角"+ 新增场次"按钮打开弹窗，场次列表表格展示：场次名称 / 时间 / 成团规则 / 规格和价格 / 操作（修改、删除）。
  • 弹窗分三步设置：
    • ① 基础信息：填写场次名称；点击时间框弹出日历，支持多选、可离散选择日期。
    • ② 规格设置：主类型默认存在（如：学生），可"添加其他类型"（如：家长）；每个类型下可添加多个规格，配置规格名称、价格（元/人）、年龄限制（可启用起止年龄段）。
    • ③ 成团规则：按主类型所有规格购买数量合计计算——设置最低成团人数与购买上限人数；设置活动开始前最晚确认 X 天。
